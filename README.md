| Network | VLAN | Subnet | Purpose |
|---|---|---|---|
| Management | — | 172.16.16.0/24 | Ansible SSH access to compute nodes, internet access for package downloads |

## Network Details

### Management — 172.16.16.0/24

### ctlplane — VLAN 30 — 172.16.30.0/24
Primary control plane network. OpenStack operator uses this to communicate with compute nodes. dnsmasq DNS service runs on this network and provides DNS resolution for all OpenStack services. MetalLB LoadBalancer VIPs for ctlplane services are assigned from this subnet.

### internalapi — VLAN 102 — 172.17.0.0/24
All internal OpenStack API endpoints are exposed on this network. Services like Keystone, Nova API, Cinder API, Neutron API, Placement share the VIP `172.17.0.80`. RabbitMQ message bus also runs on this network.

### storage — VLAN 20 — 10.10.20.0/24
Dedicated network for Ceph storage traffic.  network to communicate with the Ceph cluster at `10.10.20.20`.

### tenant — VLAN 104 — 172.19.0.0/24
OVN uses this network for Geneve tunnel encapsulation between compute nodes. All VM-to-VM traffic across hypervisors traverses this network encapsulated in Geneve tunnels.

### external 
Provider network uplink. The `ens36` NIC is placed raw into `br-datacentre` OVS bridge. Neutron maps `datacentre` physical network to this bridge allowing VMs to get IPs directly on the provider network.
